---
title: Authentication
description: How to authenticate with the VM0 API
---

All API requests require authentication using a Bearer token in the `Authorization` header.

## Token Format

API tokens follow this format:

```
vm0_live_<64 hex characters>
```

Example: `vm0_live_a1b2c3d4e5f6...`

## Using the Token

Include your token in the `Authorization` header with the `Bearer` prefix:

```bash
curl https://www.vm0.ai/v1/agents \
  -H "Authorization: Bearer vm0_live_xxx"
```

## Obtaining a Token

### Via CLI

The easiest way to get a token is through the VM0 CLI:

```bash
vm0 auth login
```

This creates a token and stores it in your local configuration. To view your token:

```bash
vm0 auth setup-token
```

### Via API

You can also create tokens programmatically using an existing token:

```bash
curl https://www.vm0.ai/v1/tokens \
  -H "Authorization: Bearer vm0_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-new-token", "expires_in_days": 90}'
```

See [Tokens API](/docs/reference/api/tokens) for full details.

## Token Expiration

Tokens expire after a configurable number of days (default: 90 days). The expiration date is returned when creating a token and can be checked via the Tokens API.

When a token expires, you'll receive a `401` error with the code `expired_api_key`:

```json
{
  "error": {
    "type": "authentication_error",
    "code": "expired_api_key",
    "message": "API key has expired"
  }
}
```

## Token Security

<Callout type="warning">
  Keep your API tokens secure. Never commit them to version control or share them publicly.
</Callout>

Best practices:

- Store tokens in environment variables
- Use short expiration times for automated systems
- Rotate tokens regularly
- Revoke tokens immediately if compromised

## Error Responses

| Status | Code | Description |
|--------|------|-------------|
| 401 | `missing_api_key` | No Authorization header provided |
| 401 | `invalid_api_key` | Token is malformed or doesn't exist |
| 401 | `expired_api_key` | Token has expired |
| 401 | `revoked_api_key` | Token was revoked |
