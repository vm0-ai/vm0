## What is GraphQL

GraphQL is a query language for APIs. Unlike REST where each endpoint returns fixed data, GraphQL lets you request exactly the fields you need in a single request.

**Key differences from REST:**

| REST | GraphQL |
|------|---------|
| Multiple endpoints (`/runs`, `/runs/123`) | Single endpoint (`/api/graphql`) |
| Fixed response structure | You choose which fields to return |
| GET/POST/PUT/DELETE | Always POST |
| Over-fetching or under-fetching | Get exactly what you need |

## How It Works

All requests go to a single endpoint:

```
POST https://vm0.ai/api/graphql
```

The request body contains your query:

```json
{
  "query": "...",
  "variables": { ... }
}
```

## Available Operations

### Queries (read data)

| Operation | Description |
|-----------|-------------|
| `run(id)` | Get a single run by ID |

### Mutations (write data)

| Operation | Description |
|-----------|-------------|
| `createRun(input)` | Start a new agent run |

### Subscriptions (real-time)

| Operation | Description |
|-----------|-------------|
| `runEvents(runId)` | Stream events from a running agent |

## Examples

### Get a Run

```bash
curl -X POST https://vm0.ai/api/graphql \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_KEY" \
  -d @- << 'EOF'
{
  "query": "{ run(id: \"run_abc123\") { id status prompt createdAt } }"
}
EOF
```

Response:

```json
{
  "data": {
    "run": {
      "id": "run_abc123",
      "status": "completed",
      "prompt": "Create a hello world script",
      "createdAt": "2025-01-08T10:00:00Z"
    }
  }
}
```

### Create a Run

```bash
curl -X POST https://vm0.ai/api/graphql \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_KEY" \
  -d @- << 'EOF'
{
  "query": "mutation ($input: CreateRunInput!) { createRun(input: $input) { run { id status } } }",
  "variables": {
    "input": {
      "agentId": "agent_xyz789",
      "prompt": "Create a hello world script"
    }
  }
}
EOF
```

### Subscribe to Events

```bash
curl -N https://vm0.ai/api/graphql \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Accept: text/event-stream" \
  -d @- << 'EOF'
{
  "query": "subscription { runEvents(runId: \"run_abc123\") { eventType eventData } }"
}
EOF
```

## Types Reference

### Run

| Field | Type | Description |
|-------|------|-------------|
| `id` | ID | Unique identifier |
| `status` | RunStatus | pending, running, completed, failed, timeout |
| `prompt` | String | User prompt |
| `result` | JSON | Output when completed |
| `error` | String | Error message when failed |
| `createdAt` | DateTime | Creation time |
| `startedAt` | DateTime | Start time |
| `completedAt` | DateTime | Completion time |

### RunEvent

| Field | Type | Description |
|-------|------|-------------|
| `id` | ID | Event identifier |
| `eventType` | String | assistant, tool_use, tool_result, error, complete |
| `eventData` | JSON | Event payload |
| `timestamp` | DateTime | When it occurred |

## Errors

```json
{
  "errors": [{ "message": "Not authenticated", "extensions": { "code": "UNAUTHENTICATED" } }]
}
```

| Code | Meaning |
|------|---------|
| `UNAUTHENTICATED` | Missing or invalid API key |
| `NOT_FOUND` | Resource doesn't exist |
| `FORBIDDEN` | No permission |
