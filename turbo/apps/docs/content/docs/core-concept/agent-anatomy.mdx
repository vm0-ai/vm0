A VM0 agent is composed of two fundamental building blocks: a **Container Image** and a **Volume**.

```
┌─────────────────────────────────────────┐
│                 Agent                   │
├─────────────────────────────────────────┤
│  ┌─────────────────────────────────┐    │
│  │       Container Image           │    │
│  │  (Runtime environment, tools)   │    │
│  └─────────────────────────────────┘    │
│                  +                      │
│  ┌─────────────────────────────────┐    │
│  │           Volume                │    │
│  │  (Instructions, skills, files)  │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘
```

## Container Image

The [Container Image](/docs/core-concept/container-image) provides the runtime environment for your agent. It includes:

- The Agent Provider (Claude Code or Codex)
- System tools and dependencies
- Base configuration

You can use VM0's default images or create custom images with additional tools. To learn how to install tools like `ffmpeg`, `chromium`, or other dependencies, see [Container Image](/docs/core-concept/container-image).

## Volume

The Volume contains everything specific to your agent's task:

- **Instructions** - What the agent should do
- **Skills** - Reusable capabilities and integrations
- **Files & Scripts** - Supporting files for the agent and scripts used by skills

## Syntactic Sugar

VM0 provides convenient abstractions for building volumes:

### Instruction (`AGENTS.md`)

The [Instruction](/docs/core-concept/instruction) file (`AGENTS.md`) defines what your agent should do. It's automatically included in the volume and passed to the LLM as system context.

```markdown title="AGENTS.md"
# My Agent

You are an assistant that helps with code reviews.

## Guidelines

- Focus on code quality
- Suggest improvements
```

### Skills

[Skills](/docs/core-concept/skill) are reusable packages that add capabilities to your agent. They can include:

- Additional instructions
- Environment variable definitions
- Files and tools

```yaml title="vm0.yaml"
version: "1.0"

agents:
  my-agent:
    provider: claude-code
    skills:
      - https://github.com/vm0-ai/vm0-skills/tree/main/github
```

When you add a skill, its contents are merged into your agent's volume.

## How It Works

When you run `vm0 cook` or `vm0 run`:

1. VM0 builds a volume from your `AGENTS.md`, skills, and local files
2. The volume is mounted into the container image
3. The agent runs with access to everything in the volume

This separation allows you to:

- **Reuse images** across different agents
- **Share skills** between projects
- **Version control** your agent's behavior independently from the runtime
