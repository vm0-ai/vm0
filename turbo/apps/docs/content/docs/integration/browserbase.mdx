[Browserbase](https://www.browserbase.com/) is a cloud browser infrastructure service that provides managed browser sessions for AI agents and automation workflows with Playwright and Puppeteer support.

## Required Secrets

| Secret                   | Description                                                         |
| ------------------------ | ------------------------------------------------------------------- |
| `BROWSERBASE_API_KEY`    | API key from [Browserbase Dashboard](https://www.browserbase.com/) |
| `BROWSERBASE_PROJECT_ID` | Project ID from [Browserbase Dashboard](https://www.browserbase.com/) |

## Configuration

```yaml title="vm0.yaml"
version: "1.0"

agents:
  my-agent:
    provider: claude-code
    skills:
      - https://github.com/vm0-ai/vm0-skills/tree/main/browserbase # [!code highlight]
    environment:
      BROWSERBASE_API_KEY: "${{ secrets.BROWSERBASE_API_KEY }}" # [!code highlight]
      BROWSERBASE_PROJECT_ID: "${{ secrets.BROWSERBASE_PROJECT_ID }}" # [!code highlight]
```

## Run

```bash
vm0 run my-agent "automate browser tasks" \
  --secrets BROWSERBASE_API_KEY=xxx \
  --secrets BROWSERBASE_PROJECT_ID=xxx # [!code highlight]
```

You use Browserbase to automate web browser tasks with persistent sessions.

## Features

### Session Management
- Create sessions with custom timeouts and keepAlive settings
- Filter sessions by status (RUNNING, ERROR, TIMED_OUT, COMPLETED)
- Live debugging with Chrome DevTools
- Session recording retrieval

### Context Persistence
- Save cookies, cache, and session storage
- Restore authentication across multiple sessions
- Automatic context updates after session completion

### Limitations
- Free plans limited to 1 concurrent session
- Proxy support requires paid plans
