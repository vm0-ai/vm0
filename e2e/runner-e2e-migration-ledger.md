# Runner E2E migration ledger

This ledger accounts for every `@test` removed from `e2e/tests/03-runner` by
commit `7ae186e0c9b04199101dd052459062e4dc916d09`. A case is classified as:

- `real-api-e2e`: the replacement goes through Clerk authentication and public
  product APIs, then reaches the deployed API, runner, and sandbox where the
  behavior requires them.
- `runner-integration`: the case exercises a runner-only input or protocol that
  is no longer a user capability. It remains at the runner, guest-agent, API
  integration, or mitm boundary and must not create a public test fixture API.

The real API suite uses the historical `runner`, `runner-real-codex`, and
`runner-real-claude` accounts in one workspace. The IDs below refer to tests in
`playwright/tests/runner-api.spec.ts`.
